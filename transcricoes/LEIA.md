# transcricoes

Transcrições de vídeos do YouTube salvas pelo **Agente de Aprendizado** (admin › Agentes; Hermes perfil `aprendizado`
na VPS2). Pedro, 28/10/2026.

Cole o link do vídeo na conversa do agente; ele abre o tactiq.io/tools/youtube-transcript no Chrome do agente (o mesmo
do Agente OLX, escondido neste PC), cola o link, espera a transcrição, clica em Copy e grava aqui
`AAAA-MM-DD <título do vídeo> [<id>].txt`. Precisa do `nay-agentes/hermes-painel/navegador-olx.bat` ligado.

Os .txt não vão para o git (são longos e o texto é de quem fez o vídeo); só este LEIA.
Como funciona: `nay-agentes/hermes-painel/mcp_transcricao.py`.
